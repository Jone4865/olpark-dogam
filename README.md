# 올팍 도감

올림픽공원 9경과 생태 공간을 찾아가 사진을 찍고 카드와 배지를 모으는 모바일 웹앱입니다. 2026년 한국체육산업개발(주) 공공데이터 활용 경진대회 출품작입니다.

## 웹앱 (`app/`)

서버 없이 정적 파일만으로 동작합니다(전체 약 250KB). 아무 정적 호스팅에 `app/` 폴더를 올리면 됩니다. 위치와 카메라를 쓰므로 HTTPS 주소여야 합니다.

```bash
python3 -m http.server 8790 --directory app   # http://localhost:8790
```

- **화면:** 시작 안내, 지도(9경·테마 지점, 내 위치), 장소(계절 카드 4칸, 공원 갤러리 사진, 잔디 개방 안내), 장소 고르기(위치가 겹칠 때), 카드(내 사진과 "그때 사진" 비교, 배지 획득), 장미 퀴즈, 도감(장소 카드·장미 도감 153종), 배지, 설정(백업·불러오기, 홈 화면 추가 안내, 데이터 출처), 위치 점검 모드
- **카드 규칙:** 지점마다 봄·여름·가을·겨울 카드가 있습니다. 배지 안의 모든 지점에서 한 장씩 모으면 배지를 받습니다. 공원 산책 배지는 공원 어디서든 네 계절을 모으면 받습니다. 장미광장에서 찍으면 장미 퀴즈가 열리고, 맞히면 그 장미 카드를 받습니다.
- **개인정보:** 사진은 기기의 IndexedDB에만 저장하고 서버로 보내지 않습니다. 저장할 때 다시 그려서 사진 속 촬영 위치 정보(EXIF)를 지웁니다. 위치는 판정에만 쓰고 저장하지 않습니다.
- **아이폰 사파리:** 7일 넘게 열지 않으면 기록이 지워질 수 있어 시작 화면과 지도에서 홈 화면 추가를 안내하고, 백업 파일 저장·불러오기를 제공합니다.
- **오프라인:** 서비스 워커가 앱 파일과 데이터를 저장해 둡니다. 공원 사진과 장미 사진은 공원 홈페이지에서 불러오고, 본 사진은 150장까지 저장해 둡니다.

## 데이터 다시 만들기

```bash
python3 -I tools/fetch_api.py        # 장미 API 2종 → tools/raw/ (인증키는 tools/.keys, 저장소에 넣지 않음)
python3 -I tools/build_zones.py      # 장소 구역 → data/zones.geojson
python3 -I tools/build_app_data.py   # 앱 데이터 → app/data/*.json
node tools/test_app.mjs http://localhost:8790/ /tmp/olpark-test 시험사진.jpg   # 헤드리스 크롬 흐름 시험
```

# 수집 구역

올림픽공원에서 장소에 가서 사진을 찍고 카드를 모으면 배지를 주는 서비스의 위치 기준 파일입니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `data/zones.geojson` | 배지 14개, 지점 31곳의 구역. 판정 규칙(`rules`), 배지 목록(`badges`), 겹치는 지점(`overlaps`)도 들어 있음 |
| `data/zones_preview.svg` | 검수용 그림. 실선은 OpenStreetMap 경계, 점선은 공식 안내도 기준 |
| `tools/build_zones.py` | 위 두 파일을 다시 만드는 스크립트 (`python3 -I tools/build_zones.py`) |
| `tools/osm_olpark.json` | OpenStreetMap에서 추린 경계와 배경 |
| `tools/georef_points.tsv` | 공식 안내도 좌표를 실제 위경도로 바꾸는 기준점 19개 |
| `tools/gallery_titles.tsv` | 공원 홈페이지 생태갤러리 사진 제목 268개 (배지별 사진 수 세기용) |

## 배지

- **9경** (공식 9경 그대로): 세계평화의문, 엄지손가락, 몽촌해자, 대화, 몽촌토성 산책로, 나홀로나무, 88호수, 들꽃마루, 장미광장
- **테마**: 명품 나무(보호수 등 5그루), 잔디마당(잔디시설정보의 장소), 조각 산책, 야생화학습장
- **어디서나**: 공원 산책 (공원 안 어디서든. 낙엽의거리·벚꽃길처럼 위치를 특정하기 어려운 계절 사진용)

## 위치 판정

각 지점은 점 + 반경(`radius_m`) 또는 경계 + 여유(`buffer_m`)입니다.

1. 폰이 알려 준 오차가 50m보다 크면 판정을 미루고 "조금 이동해 주세요"를 띄운다.
2. `현재 위치와 지점 도형 사이 거리 <= 반경(또는 여유) + 폰 오차`이면 후보.
3. 후보가 2곳 이상이면 가까운 순서로 보여 주고 사용자가 고른다. 사진 1장은 지점 1곳만 채운다.

붙어 있어서 항상 선택 화면이 뜨는 곳은 14쌍입니다 (예: 은행나무 보호수와 내성농장, 들꽃마루와 장미광장). 실제로 붙어 있는 장소라 정상입니다. 전체 목록은 `zones.geojson`의 `overlaps`에 있습니다.

## 좌표 출처와 정확도

- **OpenStreetMap 기준 15곳**: 경계가 실제 지도와 같습니다.
- **공식 안내도 기준 16곳** (`field_check: true`): 올림픽공원 홈페이지 안내도(그림 지도)의 위치를 기준점 19개로 실제 좌표에 맞췄습니다.
  - 기준점 하나씩 빼고 맞춰 본 오차는 중앙값 약 23m, 최대 약 60m입니다.
  - 홈페이지 안내도의 장소 목록 좌표는 실제 그림과 어긋난 것이 많아서(예: 장미광장 표시가 테니스장 옆에 찍힘) 쓰지 않았습니다. 그림에 그려진 위치를 직접 읽었습니다.
- 현장에서 한 번 걸어 보며 점선 지점을 확인해야 합니다. 앱의 점검 모드(현재 좌표와 판정 결과 표시)로 확인할 예정입니다.

## 아직 못 넣은 것

- 잔디시설정보의 **전시마당**: 안내도에 없어서 위치를 모릅니다.
- **서울의 만남(조각)**, **몽촌뜰**: 정확한 위치를 확인하지 못했습니다.
- 수목정보와 장미광장 API의 실제 항목: 인증키를 받은 뒤 카드 내용에 연결합니다.
